# CotiTrama Web

Frontend Angular 22 standalone con SSR en Lambda y NgRx SignalStore por flujo. Consulta las instrucciones completas en [README del producto](../README.md).

`npm ci` instala las versiones del lockfile. `npm run build` compila browser/server; desde la raíz `npm run build` prepara además `web/dist/lambda`. `npm test -- --watch=false` verifica componentes y flujos. Para ejecutar la demostración completa usa `npm run demo` desde la raíz.
